# Recotte Studio Project Samples

このディレクトリには、ファイル形式の解析と自動テストに使用する、Recotte Studio が生成した有効なプロジェクトファイルを収録しています。解析結果は [Documents/RecotteProjectFormat](../../Documents/RecotteProjectFormat/README.md) を参照してください。

## 管理方針

- このディレクトリには Recotte Studio が生成したプロジェクトだけを置く。
- シナリオごとにディレクトリを作り、その中にプロジェクトファイルを置く。
- プロジェクトが外部素材を参照する場合は、可能な限り同じサンプルディレクトリで素材を管理する。
- パス、ファイル名、プロジェクト内容に個人情報を含めない。
- 文字コードは UTF-8、改行コードは CRLF とする。

## 次に作成するサンプル

### `010OneAnnotationText`

以下の名前で保存してください。

- ディレクトリ: `Samples/RecotteProjects/010OneAnnotationText`
- プロジェクト: `010OneAnnotationText.ccproj`

空に近いプロジェクトを作成し、注釈トラックへ次の文字クリップを1つだけ追加します。

- 文字: `編集メモ：ここから明るいBGM。音量はナレーションより控えめ。`
- 開始位置: 1秒
- 終了位置: 6秒

形式の差分を明確にするため、ほかのキャラクター、音声、画像、動画、図形、文字クリップは追加しません。
文字スタイル、位置、色、注釈トラックの表示状態などは、可能な限りRecotte Studioの初期値のまま保存してください。
動画への表示を抑制する設定については、このサンプルを解析した後、必要に応じて別の比較用サンプルを用意します。
